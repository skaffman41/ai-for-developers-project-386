# Agent instructions

Учебный проект Hexlet «Календарь звонков».

- Сохраняй `.github/workflows/hexlet-check.yml` без изменений.
- Для workflow используй Matt Pocock Skills. OpenSpec не устанавливай.

## Agent skills

### Issue tracker

Задачи и спецификации — локальные Markdown-файлы в `.scratch/`. Перед созданием, чтением или обновлением задач читай `docs/agents/issue-tracker.md`.

### Triage labels

Роли triage — значения локального поля `Status:`. Перед сменой роли читай `docs/agents/triage-labels.md`.

### Domain docs

Используется single-context: корневой `GLOSSARY.md` и `docs/adr/`. Перед исследованием проекта читай `docs/agents/domain.md`.
