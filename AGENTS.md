# Agent instructions

Учебный проект Hexlet «Календарь звонков».

- Сохраняй `.github/workflows/hexlet-check.yml` без изменений.
- Для workflow используй Matt Pocock Skills. OpenSpec не устанавливай.

## Development workflow

Перед подготовкой плана, реализацией или коммитом читай [development-workflow.md](docs/agents/development-workflow.md).

- Согласованные спецификацию и тикеты фиксируй отдельным коммитом до реализации.
- Перед стартом проверь Git, спецификацию, тикет и завершённость зависимостей; сохраняй чужие незакоммиченные изменения.
- `$implement <id>` запускает один цикл указанной задачи: найди тикет по короткому идентификатору, прочитай его и назови заголовок. Например: `$implement 02-run-application`.
- Выполни критерии приёмки и предусмотренные проверки. Независимый code-review запускай при существенных изменениях, когда есть содержательный предмет для ревью; сам вызов `$implement` не делает его обязательным.
- Каждую завершённую задачу фиксируй отдельным Conventional Commit: `type(scope): description`, scope необязателен. Включай только относящиеся к задаче изменения.
- Следующую задачу запускай только по отдельному запросу. Push требует явного разрешения.

## Tool Failure Recovery

При ошибке установи причину и попробуй безопасный альтернативный маршрут через уже установленные CLI, официальные API или штатные средства. После первой ошибки читай [tool-recovery.md](docs/agents/tool-recovery.md); блокировку фиксируй только после исчерпания разумных альтернатив, а `resolved` — после выполнения всех критериев.

## Agent skills

### Issue tracker

Задачи и спецификации — локальные Markdown-файлы в `.scratch/`. Перед разрешением короткого идентификатора, созданием, чтением или обновлением задач читай [issue-tracker.md](docs/agents/issue-tracker.md).

### Triage labels

Роли triage — значения локального поля `Status:`. Перед сменой роли читай [triage-labels.md](docs/agents/triage-labels.md).

### Domain docs

Используется single-context: корневой `GLOSSARY.md` и `docs/adr/`. Перед исследованием проекта читай [domain.md](docs/agents/domain.md).
