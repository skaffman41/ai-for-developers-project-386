# 05: Подготовить новый клон, локальные хуки и инструкции

**Status:** resolved
**Blocked by:** 04
**What to build:** новый участник следует короткой инструкции, подготавливает клон одной командой, запускает приложение и проверки; локальный pre-commit применяет те же проверки качества.
**Спецификация:** [Каркас приложения](../spec.md#verification-commands).
**Критерии спецификации:** AC-01, AC-09, AC-11–AC-16.

Запуск: `$implement 05-hooks-and-onboarding` после завершения зависимостей. Порядок выполнения и границы разрешения — в [development workflow](../../../docs/agents/development-workflow.md).

## Критерии завершения

- [x] hk настроен на read-only pre-commit с общими задачами линтера и форматирования. Он не исправляет файлы, не добавляет их в индекс и не создаёт коммиты. Импорты конфигурации соответствуют точной версии hk; отдельный Pkl CLI не установлен.
- [x] hooks:install устанавливает hk только для текущего клона через mise. setup после npm ci вызывает установку хуков; глобальная Git-конфигурация не меняется.
- [x] check дополнен hk validate и теперь включает полный набор из спецификации. Все проверки по-прежнему работают без установленного локального hook; в CI установка хуков не нужна.
- [x] Ручной вызов pre-commit на исправном дереве проходит, а на временном нарушении линтера или форматирования возвращает ненулевой код. Рабочее дерево и индекс не переписываются; для проверки не требуется настоящий commit.
- [x] Корневые инструкции агента содержат dev, test, lint, check и правило Conventional Commits. Существующие правила проекта сохранены; личные предпочтения пользователя в общие документы не перенесены.
- [x] README содержит фактический стек и версии, короткую подготовку чистого клона, dev и отдельные команды, адреса, HOST/PORT, остановку, сборку, тесты, линтер, все проверки и хуки. Сценарии владельца календаря и гостя и сведения Hexlet сохранены.
- [x] Полный путь подготовки воспроизведён в чистом клоне либо чистой временной Git-копии без зависимостей и результатов сборки на macOS arm64; lockfiles не переписаны. Linux x64 подтверждается в задаче 06. Не созданы bootstrap framework и дополнительные команды сверх необходимого.
- [x] Защищённый workflow Hexlet остался побайтово прежним после setup, format и проверки hook. Новые автоматические тесты не добавлены.

## Answer

Выполнено **2026-11-07**, macOS arm64. Все критерии задачи 05 подтверждены; статус `resolved`.

- `hk.pkl` расширяет `Config.pkl` из пакета hk **2.11.1**, совпадающего с бинарным hk и mise lockfile. Явный `pre-commit` задаёт `fix = false`, `stage = false`, `stash = "none"`; шаги вызывают существующие `mise run lint` и `mise run format:check` для всего рабочего дерева. Builtins с автоисправлениями не подключены, отдельный Pkl CLI не установлен.
- `hooks:install` выполняет локальный `hk install --mise`. `setup` после проверки версий последовательно запускает `npm ci` и `mise run hooks:install`. В текущем клоне и чистой временной копии установлен `.git/hooks/pre-commit`, вызывающий hk через `mise x`. Глобальная Git-конфигурация сохранена.
- `check` использует прежние общие задачи и дополнительно выполняет `hk validate`; зависимость `test → build → env:check` сохранена, обе части собираются один раз до smoke. Установка hook для `check` не нужна.
- В `AGENTS.md` добавлены команды `dev`, `test`, `lint`, `check` и ссылка на README. Правило Conventional Commits и все прежние проектные инструкции сохранены; личные предпочтения в общий файл не переносились.
