# 02: Запустить воспроизводимый frontend и backend

**Status:** resolved
**Blocked by:** 01
**What to build:** разработчик подготавливает окружение из корня, запускает обе части одной командой, открывает страницу каркаса и получает успешный ответ backend; обе части также собираются и запускаются после сборки.
**Спецификация:** [Каркас приложения](../spec.md).
**Критерии спецификации:** AC-01–AC-05, AC-11, AC-12, AC-16–AC-18.

Запуск: `$implement 02-run-application` после завершения зависимостей. Порядок выполнения и границы разрешения — в [development workflow](../../../docs/agents/development-workflow.md).

- [x] Использован проверенный набор из Answer задачи 01. Приватные frontend и backend объединены npm workspaces с одним корневым lockfile; все внешние прямые зависимости, включая инструменты следующих задач, указаны точными версиями.
- [x] До первой фактической установки выполнен успешный npm dry-run полного набора с включёнными engine-strict и strict-peer-deps и без lifecycle scripts. Результат записан в Answer. При конфликте набор корректируется и повторно проверяется до установки; force и legacy-peer-deps не используются.
- [x] Node и hk зафиксированы через mise, mise lockfile поддерживает macOS arm64 и Linux x64. Версия mise описана в короткой инструкции подготовки; проверка окружения отклоняет несовпадение ожидаемых mise, Node и npm.
- [x] После первой установки создан общий npm lockfile; повторный npm ci проходит без его изменения. Генерируемые результаты, зависимости и локальные env-файлы игнорируются Git.
- [x] mise run dev запускает страницу «Календарь звонков» с подписью «Каркас приложения» и backend с GET /health: HTTP 200, JSON с единственным полем status со значением ok. Страница проверена в браузере; запуск не требует секретов, БД и внешних сервисов.
- [x] Работают отдельные dev-команды, HOST/PORT backend и значения по умолчанию из спецификации. Занятый явно выбранный порт даёт ошибку; Ctrl+C общего запуска и ошибка старта одной части завершают принадлежащие ему процессы.
- [x] mise run build собирает обе части; start:backend и preview:frontend запускают результаты сборки. Строгая проверка типов работает для обеих частей; настройки ESM и запуска TypeScript соответствуют спецификации.

- [x] Предоставленный workflow Hexlet сохранён побайтово. Дополнительная инфраструктура и бизнес-логика бронирований не созданы; автоматический smoke добавляется в задаче 03.
