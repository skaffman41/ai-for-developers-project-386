# Отдельный публичный маршрут записи

Главная страница сервиса ведёт на отдельный публичный маршрут `/booking`. Он должен открываться по прямой ссылке и после обновления страницы: адрес записи становится самостоятельной точкой входа для гостя.

На этапе главной страницы бронирование ещё не реализовано, поэтому `/booking` показывает заголовок «Запись на встречу», сообщение «Онлайн-запись скоро появится» и ссылку «На главную». Рабочий переход на явно обозначенную заглушку позволяет проверить путь гостя до появления бронирования; неактивная кнопка такого перехода не даёт. Изменение публичного адреса в дальнейшем потребует учитывать уже существующие ссылки на запись.
