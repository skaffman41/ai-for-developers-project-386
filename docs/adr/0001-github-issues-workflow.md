# GitHub Issues и согласованный план в Git

GitHub Issues репозитория `skaffman41/ai-for-developers-project-386` становится каноническим трекером карт, спецификаций и задач вместо локальных Markdown-записей: это даёт общую историю обсуждения и native связи родителя и блокеров, требуемые этапом 3. Завершённая история этапа 2 импортирована с проверяемыми источниками, а `.scratch/` остаётся неизменяемым архивом.

Согласованный план дополнительно сохраняется версионированным снимком в Git отдельным коммитом до реализации. Это сохраняет воспроизводимую базовую линию при изменяемых статусах и обсуждении GitHub; изменение требований требует новой версии снимка. Локальная готовность в одном согласованном графе позволяет продолжать его интеграционную ветку, а Issues реализации закрываются после merge в `main`, сохраняя границу между готовностью результата и его интеграцией.
