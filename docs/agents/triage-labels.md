# Triage roles: GitHub labels

Метки triage используются в GitHub Issues целевого репозитория. У каждой классифицированной открытой задачи реализации ровно одна категория и одна роль triage; при смене роли замени прежнюю, сохранив категорию. Категория и triage описывают задачу, а назначение и причина закрытия — выполнение.

| Категория     | Значение                                              |
| ------------- | ----------------------------------------------------- |
| `bug`         | Наблюдаемое поведение нарушает согласованный контракт |
| `enhancement` | Новая возможность или улучшение                       |

| Роль Matt Pocock Skills | Значение                                          |
| ----------------------- | ------------------------------------------------- |
| `needs-triage`          | Нужна оценка сопровождающим                       |
| `needs-info`            | Не хватает информации                             |
| `ready-for-agent`       | Текст достаточно определён для выполнения агентом |
| `ready-for-human`       | Необходимо участие человека                       |
| `wontfix`               | Задача отклонена                                  |

`ready-for-agent` не разрешает всю очередь и не доказывает выполнение блокеров. `wontfix` сопровождается причиной в комментарии и закрытием `not_planned`; он не разблокирует зависимые задачи. Перед изменением меток перечитай текущее состояние, после записи проверь инвариант категории и роли. Не удаляй несвязанные метки.

## Execution and types

Назначение исполнителя и комментарий с веткой обозначают начало работы. `claimed`, `resolved` и `implementation-ready` не являются ролями triage. Локальную готовность, завершение и причины закрытия определяет раздел [«Готовность и завершение»](development-workflow.md#готовность-и-завершение); операции трекера описаны в [issue-tracker.md](issue-tracker.md).

Метки `type:map`, `type:spec`, `type:research`, `type:prototype`, `type:grilling`, `type:task` описывают вид записи и не заменяют категорию либо triage. Карты и задачи решений обходятся без triage; задачи реализации с `type:task` используют таблицы выше. Существующие стандартные метки GitHub могут сохраняться для дополнительной классификации, но не служат вторым состоянием triage.
