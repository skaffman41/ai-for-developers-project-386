## Обнаружение и чтение инструкций

- **WebStorm, 2026-11-07:** в новом сеансе Codex через Add Context → Skills → поиск `implement` показаны ручные команды Implement и Implement Spec. Это проверка доступности в интерфейсе, а не запуск реализации.
- **Codex, новый процесс, 2026-11-08:** `skills/list` с `forceReload` обнаружил включённые `implement`, `implement-spec`, `grill-with-docs`, `setup-matt-pocock-skills`, `to-spec`, `to-tickets`, `triage`, `wayfinder`; список ошибок пуст. Исходные SKILL.md только прочитаны.
- **Свежий сеанс CLI, read-only, 2026-11-08:** правильно названы GitHub Issues, репозиторий, `mise run check`, объём обоих режимов и границы публикации/закрытия. Полностью прочитаны глобальные `implement`/`implement-spec`, проектные инструкции, ADR и четыре документа снимка с проверкой SHA-256. Для #4 определены прямой блокер #3 и транзитивный #2. Использован Codex CLI 0.165.0 с настроенной моделью `gpt-6.1-sol`, без выбора другой модели:

  ```sh
  HTTPS_PROXY= https_proxy= ALL_PROXY= all_proxy= codex exec --ephemeral \
    --sandbox read-only --cd <repo> --output-last-message <tmp> - < <prompt>
  ```

Свежий CLI подтвердил конфигурацию и согласованный снимок, но не актуальные Issues: первая попытка gh остановилась на недоступном proxy; отдельная попытка прямого GET получила ошибки DNS, HTTP 504 и timeout. Явный запрет sandbox не установлен. Актуальные тела, все комментарии и native-связи прочитаны отдельно исполнителем через GitHub API; источники этих двух проверок не смешиваются.

## Команды и границы проверки

В выделенном worktree 2026-11-08 прошёл существующий `mise run check`: версии, ESLint, Prettier, типы, обе сборки, Vitest (один существующий файл/тест HTTP smoke) и `hk validate`. Для HTTP smoke разрешён localhost, ранее блокировавшийся sandbox с `listen EPERM`; проверки не отключались. Дополнительно прошли проверка YAML парсером Prettier, 12 локальных ссылок/якорей и `git diff --check`. Сравнение архива и Hexlet выполнено через `git show`, снимка — с `9792c01`, глобальных скиллов — по исходным SHA-256 и команде из [skills.md](skills.md#проверка-установленного-набора). Новые тесты не добавлялись.

GitHub проверяется закреплённым `mise exec -- gh api --paginate`: тела и комментарии текущих Issues, полный список открытых/закрытых Issues, `parent`, `sub_issues`, `dependencies/blocked_by` и метки. Проверки API выполняют только чтение; назначение и отчёты ведутся отдельно по разрешённому workflow.

Итоговое независимое ревью 2026-11-08 завершено: Standards — 0 замечаний, Spec — 0. Локальный SHA задачи и отчёт фиксируются в [#4](https://github.com/skaffman41/ai-for-developers-project-386/issues/4) после коммита. До merge Issues реализации остаются открытыми.

Удалённый запуск app-check на PR не выполняется: push и создание PR не были поручены. Здесь подтверждаются конфигурация событий и локальный полный check; результат GitHub Actions не заявляется. Публикация кода и merge в main остаются отдельными действиями.
