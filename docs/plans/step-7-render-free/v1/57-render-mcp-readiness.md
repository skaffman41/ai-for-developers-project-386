[Спецификация #55 — Шаг 7: Docker и бесплатный публичный стенд на Render](https://github.com/skaffman41/ai-for-developers-project-386/issues/55).

## What to build

Сопровождающий подключает агента к официальному MCP Render по воспроизводимой безопасной инструкции и получает проверенный маршрут ручной выкладки именно на Free-тариф. До создания сервиса подтверждены доступные операции, способ авторизации, доступ к исходному репозиторию и возможность явно отключить автоматические обновления.

Результат можно проверить независимо от Docker-реализации: агент авторизуется, выполняет разрешённую операцию чтения и сопоставляет доступные MCP-возможности с бесплатным ручным маршрутом публикации. Эта подготовка заранее выявляет ограничения MCP вместо обнаружения их только во время выкладки.

## Acceptance criteria

- [ ] В репозитории есть проектная конфигурация подключения выбранного агента либо безопасный шаблон и воспроизводимая инструкция подключения официального MCP Render.
- [ ] Авторизация выполнена документированным способом, допустим вход через браузер. Реальные ключи, токены и OAuth-сессии остаются в пользовательском окружении и не попадают в Git или отчёт.
- [ ] Агент через подключённый MCP успешно выполняет операцию чтения. В отчёте названы фактически доступные инструменты и их значимые параметры; наличие alpha-инструментов Blueprint не предполагается только по документации.
- [ ] Для доступных операций подтверждён маршрут первоначальной публикации и последующих ручных обновлений Docker-сервиса с явным тарифом Free, без постоянного диска и внешней платной БД. Подтверждены способы отключить автодеплой приложения и автоматическое применение Blueprint.
- [ ] Доступ Render к исходному репозиторию проверен отдельно от авторизации MCP; необходимость действий пользователя при авторизации описана конкретно без запроса секретов в чат.
- [ ] Подготовлена воспроизводимая безопасная конфигурация будущей бесплатной выкладки из основной ветки и инструкция ручного обновления. Сама эта задача не создаёт сервис и не выкладывает приложение.
- [ ] Если текущий MCP не позволяет выполнить выбранный бесплатный маршрут, сохранены конкретная диагностика и достигнутый результат. Задача не объявляется выполненной, платный ресурс или другой канал публикации не выдаются за решение.
- [ ] Документация и настройки согласованы с бюджетом 0 ₽, ручным моментом деплоя и ограничениями учебного стенда. Подготовка проверена применимыми существующими проверками проекта и полным `mise run check`; новых тестов нет.
- [ ] Отчёт содержит версию проверенной конфигурации, результат операции чтения, подтверждённый бесплатный маршрут, способ ручного обновления и фактические ограничения. Инструкция позволяет повторить подключение из отдельного окружения.

## Testing Decisions

Применяются относящиеся к подключению и конфигурации части T8–T9 спецификации #55 и существующий общий прогон. Проверяется внешнее взаимодействие агента с реальным MCP и доступность необходимого маршрута по фактическим инструментам, без создания платных ресурсов и без тестовых заглушек. Документы проверяются по ссылкам, настройкам и форматированию. Успешная авторизация не заменяет проверку возможностей бесплатной выкладки. Новые тесты не добавляются.

## Scope and handoff

Покрывает подготовительные части AC6–AC8, AC11–AC12 и AC14 родителя. Работа независима от сборки Docker-образа; фактическая публикация и пользовательский сценарий выполняются после готовности обеих задач. Изменения кода приложения и создание инфраструктуры в этот тикет не входят.
