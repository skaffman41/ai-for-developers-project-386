## Parent

[Спецификация #55 — Шаг 7: Docker и бесплатный публичный стенд на Railway](https://github.com/skaffman41/ai-for-developers-project-386/issues/55).

## What to build

Сопровождающий подключает агента к официальному MCP Railway и получает проверенный бесплатный маршрут ручной выкладки одного Docker-сервиса. Это выбранный пользователем запасной вариант из задания Hexlet после требования карты со стороны Render. Сохраняются бюджет 0 ₽, непостоянная SQLite, одна реплика и отсутствие автоматической выкладки.

## Acceptance criteria

- [ ] В репозитории есть безопасный шаблон подключения официального MCP Railway и воспроизводимая инструкция. Авторизация выполнена документированным способом; ключи, токены и OAuth-сессии остаются вне Git и отчётов.
- [ ] Агент через подключённый MCP успешно выполняет реальное чтение аккаунта и проектов/сервисов в явно определённом контексте. Названы фактически доступные инструменты, значимые параметры и ограничения; ожидаемый каталог документации отделён от живого.
- [ ] Для фактического аккаунта отдельно проверены бесплатный Free/Trial-тариф, доступные кредиты и возможность создать один Docker-сервис с бюджетом 0 ₽. Платная подписка, покупка кредитов, постоянный том и внешняя БД не входят в объём.
- [ ] Доступ Railway к исходному репозиторию и выбранной основной ветке проверен отдельно от авторизации MCP, без создания сервиса. Нужные действия авторизации описаны конкретно без запроса секретов в чат.
- [ ] Подготовлены поддерживаемые платформой настройки будущего Docker-сервиса: один экземпляр, PORT платформы, /health, подготовленная пустая SQLite, без томов и дополнительных сервисов. Шаблон и инструкция воспроизводимы; устаревшие форматы не выдаются за рабочую конфигурацию новых сервисов.
- [ ] По фактическим MCP-возможностям подтверждён маршрут первого создания и последующих ручных обновлений из основной ветки с выключенным автодеплоем. Локальные изменения конфигурации ничего не применяют сами. Сама эта задача не создаёт инфраструктуру и не выполняет выкладку.
- [ ] Ограничения Free/Trial, возможный сброс SQLite и задержка старта описаны по фактам Railway; поведение Render не переносится автоматически. README ссылается на актуальную инструкцию.
- [ ] Выполнены применимые проверки шаблонов, ссылок, форматирования и полный существующий mise run check. Новых тестов нет; защищённый workflow Hexlet и контракт сохранены.
- [ ] Отчёт содержит версию конфигурации, доказательство MCP-read, фактический каталог, проверку исходников/тарифа, ручной маршрут и точные невыполненные критерии. Отсутствие подключения, кредитов или нужной возможности сохраняется блокировкой, а не объявляется готовностью.

## Testing Decisions

Сохраняются T1, T4, T8–T9 спецификации #55. Проверяются реальные внешние границы подключения и подготовки без создания ресурсов, существующий полный прогон и документы. Новые тесты, моки и инфраструктура не добавляются.

## Scope and handoff

Обновляет подготовительную задачу #57 в согласованном графе #55; прежние Render-доказательства сохраняются как история. #56 уже готова локально и не реализуется повторно. Фактическая публикация и публичная приёмка относятся к #58 после готовности обеих задач, отдельно разрешённых публикации кода/интеграции и явной команды деплоя. Изменения кода приложения и создание ресурсов в эту задачу не входят.
