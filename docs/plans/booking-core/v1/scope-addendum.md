## Дополнение к охвату принятой спецификации

Статус: согласовано пользователем 2026-11-09 вместе с графом из семи задач явным ответом «Согласовываем».

Прежняя спецификация исключала автоматический выпуск; текущий запрос явно добавляет настройку release-please. Согласовано: одна версия приложения со стратегией simple; первый выпуск 0.1.0; единый Release PR по Conventional Commits, явный ручной merge, тег и GitHub Release. GITHUB_TOKEN и явный dispatch app-check на release-ветке; необходимая настройка создания PR в Actions. npm publish, deployment и контейнеризация не добавляются.

Подтверждённые факты: у репозитория нет существующих тегов/GitHub Releases; default branch main; workspaces приватные и не имеют версий; Actions default read, создание/одобрение PR отключено. Секреты не запрашивались и не сохранялись; внешние настройки только прочитаны.
