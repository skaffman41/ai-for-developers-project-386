## What to build

Сопровождающий меняет единственный исходный контракт TypeSpec и одной командой получает все производные артефакты. Гость и владелец календаря продолжают пользоваться прежним приложением, а проверка контракта выявляет любое расхождение без исправления сохранённых файлов перед сравнением.

## Acceptance criteria

- [ ] TypeSpec описывает все шесть действующих операций, включая health; OpenAPI 3.1 генерируется из него. Сопоставление с базовым контрактом подтверждает сохранение путей, методов, operationId, параметров, заголовков, JSON-полей, обязательности, ограничений, успешных статусов и ошибок. Параллельного редактируемого описания контрактных данных нет.
- [ ] mise run api:generate выполняет TypeSpec → OpenAPI → существующие SDK, модели, серверные типы, схемы, реестр операций и документацию API. Зависимости совместимы с закреплённым toolchain и закреплены штатным lockfile; производные артефакты сохранены в Git. Повторная генерация не меняет байты и набор файлов.
- [ ] mise run api:check независимо генерирует ожидаемый результат и сравнивает весь набор, включая OpenAPI. На изменённых, отсутствующих, новых и лишних производных файлах, а также ошибке компиляции TypeSpec возвращает ненулевой код. До сравнения сохранённые файлы не перезаписываются. Проверка фактических значений производных схем сохраняется.
- [ ] Успешный api:check подтверждён из чистого локального checkout и остаётся в существующем CI. Защищённый workflow Hexlet сохранён; новый удалённый CI до разрешённой публикации не объявляется выполненным.
- [ ] Frontend использует сгенерированный SDK, backend — производные серверные типы и схемы. Сохранены строгая проверка запросов и runtime-проверка ответов, идемпотентность и гарантии бронирования. Допустима только необходимая адаптация внутренних импортов или имён производных типов.
- [ ] Проходит существующий mise run check, включая HTTP и Playwright с настоящим backend; сквозной путь владельца и гостя проверен на 320 и 1440 px. До коммита выполнено независимое Standards/Spec-ревью существенного изменения и устранены обязательные замечания.

## Testing Decisions

Спецификация T1–T3, T5–T7. Существующие команды и тесты; эквивалентность контрактов дополнительно подтверждается сопоставлением и ревью. Приёмочные временные повреждения артефактов изолированы и полностью восстановлены. Новые тесты и замена действующих генераторов не входят в объём.
