- [ ] Исходная версия и дополнение явно разделены. Для дополнения зафиксированы собственные команды и результаты генерации, повторной генерации, api:check, полного прогона и эксперимента с указанием SHA/tree и ссылками на доказательства. Старые 134 Vitest и 60 Playwright не выдаются за новый результат.
- [ ] README и актуальная документация использования контракта согласованы с цепочкой TypeSpec → OpenAPI и фактическими командами. Историческая спецификация #37 и прежний planning-снимок неизменны.
- [ ] Весь интеграционный diff проходит независимое ревью по Standards и Spec; обязательные замечания устранены, затронутые проверки повторены. На окончательном результате выполнены mise run check и git diff --check; отчёт однозначно связывает проверенное дерево с итоговым SHA.
- [ ] До разрешённой публикации результат обозначен только как локальная готовность; Issues реализации остаются открытыми. Удалённый CI текущего результата, push, PR, merge в main, новый выпуск и отметка завершения Hexlet не подменяются локальными доказательствами и не выполняются этой задачей.

## Testing Decisions

Спецификация T1–T7. Используются существующие проверки и независимое Standards/Spec-ревью всего графа; новых тестов нет. Зависимость от contract транзитивна через agent-rules, поэтому отдельный избыточный блокер не нужен. Успешный CI актуального SHA после отдельно разрешённой интеграции остаётся условием окончательного завершения шага 6.
