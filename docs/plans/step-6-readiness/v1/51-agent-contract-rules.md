## What to build

Исполнитель по корневым инструкциям однозначно определяет, какой контракт редактировать, что генерировать и как проверять результат; каждый новый коммит реализации прослеживается до своего тикета.

## Acceptance criteria

- [ ] В корневых агентных инструкциях рядом с Conventional Commits явно закреплена обязательная ссылка на выполняемый тикет для каждого нового коммита реализации.
- [ ] Названы фактический исходный контракт TypeSpec и полный фактический набор генерируемых путей после миграции, включая OpenAPI; ручное изменение производных явно запрещено.
- [ ] Указаны единая команда генерации mise run api:generate и общая проверка mise run check; соответствующие разделы workflow согласованы с этими правилами.
- [ ] Существующая опубликованная история не переписана; происхождение исторического коммита без номера сохраняется через #41 и PR #45. Все новые коммиты реализации графа ссылаются на собственные тикеты.
- [ ] Команды, пути и ссылки сверены с результатом миграции; проходят git diff --check и существующий mise run check.

## Testing Decisions

Спецификация T7 и общие правила workflow. Самопроверка документации и существующие проверки, без новых тестов. Блокер нужен для указания фактических окончательных исходных и генерируемых путей.
