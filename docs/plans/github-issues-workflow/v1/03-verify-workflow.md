# Проверить короткие команды и агентный workflow

## What to build

Новый сеанс Codex читает актуальные настройки, обнаруживает ручные команды и правильно определяет трекер, проверки и границы работы. Приложение сохраняет проходящие проверки, включая конфигурацию CI для PR.

## Acceptance criteria

- [ ] Свежий сеанс Codex в режиме чтения называет репозиторий GitHub Issues и `mise run check`.
- [ ] Подтверждены обнаружение `implement`/`implement-spec`, чтение спецификации, тикетов и зависимостей и границы разрешения обоих режимов.
- [ ] В WebStorm подтверждена доступность ручных скиллов; результаты новой сессии и UI-проверки сохранены.
- [ ] app-check запускается на push и pull request; Hexlet workflow побайтово совпадает с исходным.
- [ ] Существующий `mise run check` проходит; проведены предусмотренные ревью и проверка diff.
- [ ] Отчёты и локальные SHA записаны в Issues; Issues реализации остаются открытыми до merge, push/PR/merge не выполняются.

## Testing Decisions

Существующий полный check, свежий Codex CLI в read-only, UI-проверка WebStorm, API-чтение отчётов и статусов, сравнение архивных файлов и Hexlet workflow с базой. Новые тесты не добавлять.

## Blocked by

Перенести трекер и закрепить GitHub workflow.
