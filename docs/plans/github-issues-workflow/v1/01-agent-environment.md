# Подготовить воспроизводимую агентную среду

## What to build

Codex получает проверенные глобальные инженерные скиллы и GitHub CLI для работы с целевым репозиторием; новый разработчик может повторить подготовку по закреплённым версиям.

## Acceptance criteria

- [ ] gh 2.103.3 закреплён через mise с lock-данными macOS arm64 и Linux x64.
- [ ] Подтверждены действующая авторизация и доступ к `skaffman41/ai-for-developers-project-386`.
- [ ] Зафиксирована ревизия upstream, соответствующая всем 38 установленным Matt Pocock Skills, и команда глобальной установки этого набора для Codex.
- [ ] Исходные глобальные скиллы не изменены; личные настройки не перенесены в репозиторий.
- [ ] README описывает подготовку агента, а существующие проверки остаются работоспособными.

## Testing Decisions

Проверить версию CLI, lock обеих платформ, `gh repo view`, сравнение всех файлов скиллов с закреплённой ревизией и форматирование затронутых файлов. Новые тесты не добавлять.
