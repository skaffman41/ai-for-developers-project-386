# Перенести трекер и закрепить GitHub workflow

## What to build

История этапа 2 доступна через закрытые GitHub Issues, а новые инженерные команды используют GitHub и согласованные правила веток, снимков плана и завершения задач.

## Acceptance criteria

- [ ] Импортированы спецификация и шесть задач с полным содержимым, результатами, историей и источниками.
- [ ] Сохранены родительские и блокирующие связи; добавлена таблица старый путь/ID → Issue.
- [ ] Повторный импорт находит существующие записи; семь архивных файлов остаются побайтово неизменными.
- [ ] AGENTS.md и docs/agents описывают GitHub, категории и метки, оба режима реализации, работу с зависимостями и полномочия.
- [ ] Описаны снимки согласованных планов в Git, версии при изменении требований и завершение реализации после merge.
- [ ] Архитектурное решение сохранено в ADR; пути доменных документов сохранены.

## Testing Decisions

Прочитать созданные Issues и связи через API, сверить содержимое и исходные хеши, повторить безопасный поиск импорта без создания, проверить ссылки и `git diff --check`. Независимое ревью существенных правил workflow. Новые тесты не добавлять.

## Blocked by

Подготовить воспроизводимую агентную среду.
